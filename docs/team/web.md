# Web UI: files to push

All of these live in `src/web/`:

| File | What it is |
|---|---|
| `web_demo.py` | local server: estimator API, plus the report page's figures and PDFs |
| `index.html`, `demo.css`, `demo.js` | price estimator (decision-tree branch design) |
| `report.html`, `report-theme.css`, `app.js` | project results page |
| `site-data.js` | generated by `python -m src.experiments`; holds the results-page numbers |
| `assets/pegasold-logo.png`, `favicon.svg` | new logo and favicon (black/lime) |
| `__init__.py` | package marker |

The tests are in `tests/test_web_demo.py`.

```bash
python -m src.run_all                 # once
python -m src.web.web_demo            # http://127.0.0.1:8765
python -m src.web.web_demo --bagged   # serve the 30-tree ensemble instead of single trees
```
